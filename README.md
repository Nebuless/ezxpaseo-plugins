# EZXPaseo plugins

This repository contains local Paseo plugins.

## Plugins

- `paseo-ask-user`: Adds structured questions to an agent timeline, including topic tabs, single-choice answers, multiple-choice answers, and custom text.

## Development

Install all workspace dependencies:

```bash
npm install
```

Run formatting checks, type checks, and tests across every plugin:

```bash
npm run check
```
